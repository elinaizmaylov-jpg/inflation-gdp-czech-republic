# inflation-gdp-czech-republic
Econometric analysis of the relationship between inflation and GDP growth in the Czech Republic using OLS and FDL models in R
# Methods 
OLS regression
FDL model 
Statistical tests
# Tools 
R
# Key Findings and Limitations 
Delivered a written report with results showing the negative coefficient of lagged inflation which indicates that inflationary pressures may influence economic activity with delay; limitations of the analysis included that the study is based on a relatively small annual dataset covering only one country. Second, GDP growth is influenced by many additional macroeconomic factors that are not included in the estimated models, such as unemployment, interest rates, fiscal policy, or multiple international economic conditions.
